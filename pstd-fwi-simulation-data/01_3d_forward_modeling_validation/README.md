# 3-D Forward Modeling Validation Data

This folder contains the data for Section III-A of the manuscript, the 3-D
forward-modeling validation experiment.

## Files

- `model_3d_plot.mat`: Cell-centered 3-D material model exported from `plot_model_3d.py` (PPW = 6). It contains `eps_r`, `sigma`, `x_cells`, `y_cells`, `z_cells`, grid spacing, domain dimensions, rectangle definitions, and source coordinates.
- `waveform_results_ppw3_ppw10.mat`: Ez waveforms extracted from the saved FDTD/PSTD forward results for PPW = 3,...,10. Curves are taken at the saved frame nearest `t = 10 ns` and `z = 1.5 m`. The file includes raw and independently normalized curves, the actual time and z used for every curve, frame indices, and the FDTD PPW = 10 reference curve.

The waveform package was generated from `3D_FDTD/forward_result_3d_slices_ppw*.mat` and `3D_PSTD/forward_result_3d_slices_ppw*.mat` using `plot_fdtd_pstd_waveform_ppw3_ppw10.py` conventions. The exported model follows `plot_model_3d.py`; its rectangle z-ranges are `1.5--2.0 m` and `0--0.5 m`. The forward-result files were generated by their solver `Main.m` files, which use `1.25--2.0 m` and `0--0.75 m`, respectively.

All distances are in metres, times are in ns unless stated otherwise, and electric-field values retain the solver output units.
